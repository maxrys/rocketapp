
# Политика конфиденциальности

Исходные коды лаунчера открыты и доступны в репозитории для ознакомления
и анализа по адресу "https://github.com/maxrys/rocketapp".


## Структура приложения

Лаунчер является полноценным приложением – он не является расширением
и не требует других расширений.

Пользователь сам определяет, какое очередное приложение будет добавлено в сетку лаунчера:
- через диалоговое окно ОС;
- через перетаскивание иконки приложения в окно лаунчера.


## Модификация файловой систем

Лаунчер не работает с файловой системой – не записывает
и не читает никакие данные.


## Хранение данных

Лаунчер использует стандартный механизм `Swift Data` для хранения
"списка добавленных приложений" в локальной базе данных.

Данный список формируется по требованию пользователя для функционирования лаунчера
и представляет собой следующую информацию о каждом добавленном приложении:
- название приложения;
- bundle ID приложения;
- путь в файловой системе к приложению;
- иконка приложения.


## Другие активности

Лаунчер:
- работает в изолированной среде ОС (песочнице);
- не регистрирует нажатие пользователя;
- не получает доступ к буферу обмена;
- не отправляет и не принимает данные по сети;
- не собирает и не хранит персональные данные;
- не передаёт данные третьей стороне.
