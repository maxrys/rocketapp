
# Политика конфиденциальности

Исходные коды запускателя открыты и доступны в репозитории для ознакомления и анализа
по адресу "https://github.com/maxrys/rocketapp".

Запускатель является полноценным приложением – он не является расширением
и не требует других расширений.

Запускатель не требует никаких дополнительных прав.  
Запускатель работает в изолированной среде ОС ("песочнице") и не способен повлиять на что-либо.  
Пользователь сам определяет, какое очередное приложение будет добавлено в сетку:
- через диалоговое окно ОС;
- через перетаскивание иконки приложения в окно запускателя.

Запускатель не работает с файловой системой – не записывает и не читает никакие данные.  
Запускатель использует стандартный механизм _Swift Data_ для хранения
"списка добавленных приложений" в локальной файловой системе.  
Данный список формируется по требованию пользователя для функционирования запускателя
и представляет собой следующую информацию о каждом добавленном приложении:
- название приложения;
- bundle ID приложения;
- путь в файловой системе к приложению;
- иконка приложения.

Запускатель:
- не имеет доступа к буферу обмена;
- не отправляет и не принимает данные по внешней сети;
- не собирает и не хранит какие-либо персональные данные;
- не передаёт какие-либо данные третьей стороне.
