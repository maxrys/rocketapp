## Description

**RocketApp Launcher** is an alternative app Launcher for macOS.

Launcher is a single-window application.  
The main window of the Launcher contains a grid of 30x30 cells.  
It has 2 operating modes: viewing mode and editing mode.

In editing mode, the user can place 1 large icon or 4 small application icons in any cell of this grid.  
Application icons will remain in the same position after exiting editing mode — no automatic arrangement!  
After filling the grid, the user switches to viewing mode.  

In viewing mode, empty cells of the grid will be cropped.  
The user can click on any application icon, and that application will be launched.

Launcher supports the creation of profiles (for example, for different monitor sizes).  
Each profile can have its own individual settings and its own set of application icons.

Launcher has open-source code.  
Data is not collected.
