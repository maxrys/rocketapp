## Описание

**RocketApp Launcher** — это альтернативный запускатель приложений для macOS.

Запускатель является однооконным приложением.  
Основное окно запускателя содержит сетку размером 30x30 ячеек.  
Он имеет 2 режима работы: режим просмотра и режим редактирования.

В режиме редактирования, в любой ячейке этой сетки пользователь может разместить 1 большую или 4 маленькие иконки приложений.  
Иконки приложений останутся в том же положении и после выхода из режима редактирования — никакой автоматической расстановки!  
После заполнения сетки пользователь переходит в режим просмотра.  

В режиме просмотра пустые поля сетки будут обрезаны.  
Пользователь может кликнуть по любой иконке приложения, и данное приложение будет запущено.

Запускатель поддерживает создание профилей (например, для разных диагоналей мониторов).  
Каждый профиль может иметь свои индивидуальные настройки и собственный набор иконок приложений.

Сбор данных не ведётся.

Является программным обеспечением с открытым исходным кодом.  
Свободен от модели подписок.  
Без кода, сгенерированного ИИ.
